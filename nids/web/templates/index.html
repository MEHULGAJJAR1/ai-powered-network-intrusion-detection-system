Runtime safeguards

Implemented boundary protections

  • Exact feature validation and feature-order enforcement
  • Finite numeric/range checks and categorical length bounds
  • CSV extension/schema checks, secure filename handling and upload-size limit
  • CSV formula-prefix mitigation on exported user-controlled text
  • Rate limiting, CORS allowlist, security response headers and generic production errors
  • Prediction history bounded by a configurable retention limit

Operational boundary

Deployment expectations

This repository provides a production-oriented single-service baseline, not a turnkey packet sensor. It does not collect live traffic or authenticate users. Deploy behind TLS, identity-aware access control and an approved telemetry/packet-collection layer. For multi-replica deployments, replace local SQLite history and in-memory rate-limit storage with managed shared services.
